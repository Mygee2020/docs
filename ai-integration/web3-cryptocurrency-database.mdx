CoinGecko is the world's largest independent cryptocurrency data aggregator, tracking real-time prices, market data, and onchain analytics for coins, tokens, exchanges, NFTs, and DeFi pools across 200+ blockchain networks. This page introduces the data surface AI agents and applications can query through the CoinGecko API and MCP servers.

## Why It Matters for AI

AI agents need trustworthy, real-time crypto data to answer user questions, execute trades, track portfolios, and reason about onchain activity. CoinGecko provides that data through purpose-built interfaces:

- **REST API** — Historical and current data for coins, exchanges, NFTs, and onchain pools.
- **WebSocket** — Live price and trade streams for coins and DEX pools.
- **Webhooks** — Push notifications when prices cross targets or new tokens list.
- **MCP Server** — Direct tool access for LLM agents, no glue code required.
